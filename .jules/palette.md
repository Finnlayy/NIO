## 2024-10-05 - Disabled Buttons Swallow Keyboard Focus
**Learning:** Native `disabled` attributes on interactive elements (like buttons) completely remove them from the accessibility tree's focus order. This prevents keyboard users and screen readers from reaching the element to understand why it is disabled (e.g., discovering via a tooltip or title that a task description is required).
**Action:** Replace native `disabled` attributes with `aria-disabled="true"` for logical disabling. Ensure the `onClick` handler explicitly prevents execution when `aria-disabled` is active. Update CSS to style `[aria-disabled="true"]` identically to `:disabled` (and exclude it from hover styles), and provide context via `title` or adjacent descriptive elements so all users can discover the state requirements.
