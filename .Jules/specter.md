## 2023-10-25 - [UI Aesthetic Insight]
**Learning:** Found component hierarchy breakdowns and inconsistent color token patterns in `TradePlan` widget, specifically using hardcoded rgba backgrounds (`rgba(9,11,18,0.9)`) and explicit hex colors for borders/text (`#34d399`, `#60a5fa`) instead of utilizing explicit tailwind utilities on the base `#0a0a0c` dark-glassmorphism. Also, the data-driven component lacked an explicit Fail-Closed badge (`FeedBadge`) and some numerical values lacked tabular-nums formatting.
**Action:** Enforced mapping string tone props (`emerald`, `blue`, `rose`) into explicit Tailwind v4 classes like `bg-[#0a0a0c]/80 backdrop-blur-md` and `text-emerald-400`. Added `FeedBadge` to properly express simulated/offline feed contexts and enforced `font-mono tabular-nums` on risk-reward readouts in the `Stat` component.
