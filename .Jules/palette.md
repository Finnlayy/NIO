## 2025-03-09 - Search Keyboard Shortcut

**Learning:** Providing visual `<kbd>` elements coupled with global shortcut listeners significantly improves power-user navigation without cluttering the interface.
**Action:** Always provide `<kbd>` badges for search and primary actions, and bind them with global listeners, ensuring focus constraints (e.g. `enableOnFormTags: false`) are set so shortcuts don't interrupt typing.
