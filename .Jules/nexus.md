## 2026-09-08 - [IPC/API Integration Insight]
**Learning:** The Python backend's telemetry feed crashed on startup because the `limbs/math/` directory shadowed the standard library's `math` module, due to Python automatically inserting the script's directory at `sys.path[0]`. Furthermore, the Kraken API bridge needed to be wired securely, taking care to not expose API secrets on the command line.
**Action:** When running scripts directly inside nested directories (like `limbs/`), explicitly pop `sys.path[0]` and unload any accidentally imported shadowed modules (like `math`) to prevent `ImportError` or `AttributeError` from external packages like `numpy`. When using `subprocess` for external CLIs like kraken, use `--api-secret-stdin` and pass secrets via the `input` argument to avoid leaking credentials in the process table.
