## 2024-10-31 - [Ergonomic Global Shortcut for Console Tasks]
**Learning:** [UX speed / shortcut discovery] Scoped keyboard handlers (`onKeyDown`) in task dispatching consoles force users to repeatedly click into the specific input field before they can use hotkeys (like Cmd+Enter) to submit a task. This causes significant friction and unnecessary mouse travel when repeatedly navigating complex grids or multi-pane layouts.
**Action:** [Pattern to follow for future hotkey implementations] Expose context-independent global workflows using top-level `useEffect` keyboard listeners attached to `window`. Guard global triggers using `isTypingTarget(document.activeElement)` to ensure shortcuts do not misfire while users are typing in unrelated text fields. Store reactive dependencies (like submission functions and input text) in `useRef` to maintain clean, non-re-rendering global listeners.
